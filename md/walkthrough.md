# 在庫ヘッダーの最終最適化（検索窓＋縦2段トグル）完了報告

検索バーの利便性を最大化しつつ、2つのフィルタ（トグル）をコンパクトに収める理想的なレイアウトを実装しました。

## 実施した変更内容

### 1. 検索バーの横幅を最大化
- 2つのトグルボタンを右側で **縦にスタック（上下並び）** させることで、トグルセクションの横幅を劇的に削減しました。
- 空いたスペースを検索バーに割り当てることで、iPhoneの画面でも検索ワードがしっかり見える長さを確保しました。

### 2. 検索バーの高さに合わせた「トグルのスタック」
- 検索バー自体の高さ（約48px）を活かし、その右側に「未確認のみ」と「非表示品を表示」のトグルを上下2段で配置しました。
- ラベルとスイッチを横並び（Row）にし、全体を小型化（scale 0.8）することで、ヘッダー全体の高さを増やすことなく、1段の中にすべての要素を収めました。

### 3. 操作性と視認性の両立
- トグルが右端にスッキリとまとまったことで、誤操作を防ぎつつ、現在のフィルタ状態（ON/OFF）を一目で確認できるようになりました。

## 確認事項
- [ 検索バー ] [ 未確認スイッチ ]
              [ 非表示スイッチ ]
  という形で、右側に2つのトグルが綺麗に縦に並んでいることをご確認ください。
- これにより、垂直方向の省スペースを維持したまま、検索窓が以前よりも格段に広くなっています。
