### 3. 初期設定（最初の一回だけ）

Gitにあなたの名前とメールアドレスを登録します（誰が変更したか記録するためです）。

```powershell
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

---

### 4. このプロジェクトでGitを開始する

インストールができたら、この在庫管理システムをGitの管理下に置きます。以下の手順をターミナルで実行してください。

#### ① Gitの初期化
```powershell
git init
```

#### ② 管理対象から外すファイルを指定
GASのビルド済みファイルなどは管理する必要がないため、`.gitignore` というファイルを作成して除外します。
私がこのファイルを作成しましょうか？（作成すると、管理が非常に楽になります）

#### ③ 最初の手順（バックアップ作成）
```powershell
git add .
git commit -m "Initial commit: 正常動作確認済みバージョン"
```

これで、**「今の正常に動いている状態」が永久に保存されます。** 今後、何かを壊してしまっても、コマンド一つでこの瞬間に戻れるようになります。

まずは、Gitのインストールを試してみてください！終わりましたら、`.gitignore` の作成や具体的な使い方のレクチャーに移ります。

### Planner Response

Gitをインストールした直後は、**「VS Code（またはターミナル）の再起動」**が必要です。

Windowsが「Gitというプログラムがインストールされた」という新しい情報を、現在開いているターミナルにまだ反映できていないためです。

### 対処法
1.  **VS Codeを一度完全に閉じて、もう一度開き直してください。**
2.  開いたら、再度ターミナルで `git --version` を入力してみてください。

これでも同じエラーが出る場合は、インストール時の設定で「Gitをコマンドラインから使用する（Git from the command line and also from 3rd-party software）」という選択肢が選ばれていなかった可能性があります。

まずは **「再起動」** を試してみてください！これで解決することがほとんどです。
