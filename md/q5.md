# PCレスポンシブレイアウト実装のまとめ

ご要望通り、PC表示の際に登録フォームと履歴を左右に並べるレイアウトを実装しました。

## 実装内容

### 1. 画面幅の拡張
*   画面幅が769px以上（PC/タブレット）の場合、アプリ全体の最大幅を1200pxまで広げるようにしました。
*   ヘッダー、下部ナビゲーション、コンテンツエリアのすべてが広くなります。

### 2. 2カラムレイアウト（仕入・経費・製造・販売）
*   **左側 (450px)**: 登録フォームが表示されます。
*   **右側 (可変)**: 履歴リストが表示されます。
*   **上部**: 今月の合計などのサマリーカードが全幅で表示されます。

### 3. モバイル表示の維持
*   iPhone等のスマホ（幅768px以下）で閲覧した場合は、これまで通り縦に項目が並ぶレイアウトが維持されます。

### 4. 帳簿ダッシュボードの最適化
*   帳簿タブのダッシュボードでも、PC表示時は「収支推移グラフ」と「最新の取引履歴」を左右に並べて表示するように調整しました。

## 確認方法
*   PCのブラウザで画面幅を広げると左右2カラムになり、幅を狭めると自動的に1カラム（スマホ版）に切り替わります。
*   登録操作を行ってもレイアウトは崩れず、右側の履歴が更新されます。
