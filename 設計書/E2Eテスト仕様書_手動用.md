# 在庫管理システム E2Eテスト仕様書（手動実施用）

本ドキュメントは、開発者が手動で統合テストを実施するための手順書です。

## 1. テストの準備
1. ブラウザで `index.html` を開く。
2. 初期データが読み込まれ、「ダッシュボード（帳簿）」が表示されることを確認する。

## 2. 仕入・在庫連動テスト
| 手順 | 操作内容 | 期待値（確認ポイント） |
| :--- | :--- | :--- |
| 2-1 | 「仕入」タブを開き、新規登録フォームを入力する。<br>・仕入先: 任意<br>・品名: `Manual-Test-Part`<br>・数量: 100 | 登録ボタンが活性化すること。 |
| 2-2 | 登録ボタンを押下する。 | 下部の「進行中の仕入状況」にデータが表示されること。 |
| 2-3 | 履歴一覧のステータスを「受取検品中」→「入庫済み」に変更する。 | 変更が保存されること。 |
| 2-4 | 「在庫」タブを開き、`Manual-Test-Part` を検索する。 | 在庫数が `100` と表示されていること。 |

## 3. 製造（BOM）テスト
| 手順 | 操作内容 | 期待値（確認ポイント） |
| :--- | :--- | :--- |
| 3-1 | 「製造」タブを開き、完成品を選択する。 | 使用部品のリストが自動表示されること。 |
| 3-2 | 製造数を `1` として登録する。 | 「製造中プロジェクト」に表示されること。 |
| 3-3 | ステータスを「完了」に変更する。 | ・部品の在庫が減っていること。<br>・完成品の在庫が増えていること。 |

## 4. 販売・帳簿連動テスト
| 手順 | 操作内容 | 期待値（確認ポイント） |
| :--- | :--- | :--- |
| 4-1 | 「販売」タブを開き、売先、販売品名を入力する。<br>・販売品名には「在庫があるもの」を選択する。 | 販売単価や手数料率が自動補完されること。 |
| 4-2 | 登録ボタンを押下する。 | 「発送・取引待ち」リストに表示されること。 |
| 4-3 | ステータスを「受取り済み」または「完了」に変更する。 | 商品の在庫が「販売数」分減少すること。 |
| 4-4 | 「帳簿」タブを開き、当月を選択する。 | 販売した売上金と利益が、グラフおよび集計カードに反映されていること。 |

## 5. 異常系・バリデーション確認
- [ ] 必須項目（日付、金額、数量）を空にして登録ボタンを押した際、エラーが表示されるか。
- [ ] 0以下の数値や、不適切な文字を入力できないようになっているか。
